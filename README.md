# **AI Car Recommendation Assistant**

## **Project Overview**

AI Car Recommendation Assistant is a full-stack web application that helps users find suitable cars based on their budget, fuel type, family size, and usage requirements.

The application filters a car dataset and generates an AI-powered summary using Google's Gemini API to help users make better decisions.

## **What did you build and why? What did you deliberately cut?**

I built an AI-powered car recommendation assistant that helps users identify suitable vehicles based on their preferences. Users can enter their budget, fuel preference, family size, and usage type, and the application recommends matching cars along with an AI-generated explanation.

The goal was to reduce decision fatigue for users who are overwhelmed by the number of available car options.

Because this assignment was time-boxed to 2-3 hours, I deliberately excluded:

--User authentication
--Database integration
--User accounts and saved recommendations
--Car comparison functionality
--User reviews and ratings
--Real-time vehicle data APIs
--Advanced filtering options

Instead, I focused on building a complete working MVP that demonstrates the core value of the product.

## **What's your tech stack and why did you pick it?**

### **Frontend**

React.js
Axios
CSS

React was chosen because it allows rapid UI development and efficient state management.

### **Backend**

Node.js
Express.js

Express provides a lightweight and straightforward way to build REST APIs.

### **AI**

Google Gemini API

Gemini was used to generate recommendation summaries based on user preferences and filtered vehicle results.

### **Deployment**

Vercel (Frontend)
Render (Backend)

These platforms allowed quick deployment and sharing of a live application.

## **What did you delegate to AI tools vs. do manually? Where did the tools help most? Where did they get in the way?**

I used AI tools for:

--Brainstorming project ideas
--Generating initial code structures
--Debugging API integration issues
--Improving prompts for Gemini
--Troubleshooting deployment issues

I handled manually:

--Project scoping and feature selection
--Application architecture decisions
--Frontend and backend integration
--API testing
--Data handling and filtering logic
--Deployment setup and verification
--Final debugging and testing

AI tools significantly accelerated development and debugging.

However, AI-generated code occasionally produced inconsistencies in field names and API integrations. These issues required manual debugging and validation before deployment.
